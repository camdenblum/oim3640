About this demo

This single-page demo provides a clean, responsive UI with client-side fetch calls to local backend endpoints. It expects the following endpoints to exist while running locally:

  • /api/stock?symbol=... — returns JSON {symbol,name,price}
  • /api/weather?location=... — returns weather JSON

If those endpoints are not running, the UI will show helpful error messages.

Built for demo — run your local Flask services and use this UI.
