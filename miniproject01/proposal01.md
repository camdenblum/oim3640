## My Project Proposal

**What I'm building:** 
For my mini project, I want to analyze the lyrics from Noah Kahan’s three albums: Busyhead, Part of Me, and Stick Season. I chose this topic because I am interested in his music and I think it would be meaningful to explore patterns in his songwriting. Since text analysis is about finding something interesting in language, my project will focus on identifying repeated themes, commonly used words, and differences across the three albums.

To complete this project, I will create my own text files by gathering the lyrics myself and organizing them by album. Each album will have its own text file so that the data is clean and easy to work with in Python. This will also help me practice handling text files, which is an important beginner coding skill.

The main question behind my project is: What patterns appear in Noah Kahan’s lyrics across these three albums, and how do the albums compare? More specifically, I want to see which album uses the most unique words, which words appear most often, and whether certain themes or repeated terms show up more in one album than another. This makes the project more interesting than simply counting words, because I will be using the counts to compare writing style and lyrical focus.

I chose this topic because Noah Kahan is my favorite artist, and his music has had a strong influence on me. **Core features:** 

This project will use several beginner Python concepts that we have learned in class. These include working with variables, loops, and functions to organize the code and repeat tasks efficiently. I will also use string methods to clean and process the text, along with lists to store words and dictionaries to count word frequencies. Reading from text files will be an important part of the project since the lyrics will be stored in files that I create myself. I also plan to write simple functions to keep the program organized, such as one function to clean the text, one to count word frequencies, and another to display the results.
